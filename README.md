# rbay-design-team

Minimal export of the design-team track family — architect, idealist,
design-skeptic, scope-cutter, prior-art-researcher, red-team,
requirements-analyst, spec-writer.

**Status:** bare minimum. Just `tracks/*/wake.md` for each track,
stripped of instance-specific scry markers. No `bay.yaml`, no
capabilities/, no CI wiring yet — those land once the reflect-v2 bay
definition format spec (S1) is finalized. This is meant to be usable
today: drop a track's `wake.md` into a plain `reflect init` project's
`agent/runtime/tracks/<name>/` directory.
